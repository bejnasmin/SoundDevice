# Sound Recorder

A simple sound recording application built with Python using the `sounddevice` library.

The program records audio from the microphone for a specified duration and sample rate.

## Features

- Records audio from the microphone
- Allows you to set the recording duration
- Uses a sample rate of 44100 Hz
- Records mono audio
- Waits until the recording is completed

## Technologies

- Python
- sounddevice

## Installation

pip install sounddevice
